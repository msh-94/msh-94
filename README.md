## 💡 LC-Eye 프로젝트
> **기간:** 2025.11.05 ~ 2025.11.27 <br/>
> **기술스택:** Spring Boot · React · Flutter <br/>
> **역할:** canva / 자동 매핑 시스템 / Flutter 총괄

**LC-Eye**는 실무 LCI(Life Cycle Inventory) 계산과 표준 데이터 자동 매핑 기능을 제공하는 **경량형 LCI 시스템**입니다. <br />
복잡한 LCI 계산 과정을 자동화하고 데이터 관리의 효율성을 높이는 것을 목표로 했습니다.

**핵심 구현**
- **LCI 계산 알고리즘** : 사용자 입력 데이터를 기반으로 단위공정별 투입·산출물 총량을 계산
- **자동 매핑 시스템** : 공정 또는 재료명 입력 시 내부 DB의 표준 Process 데이터 키워드 매칭/Gemini LLM 활용 매칭
- **MSA 기반 분산 서버 구축** : Member, Project, Front 등 기능별 서버 분리/Redis Rub/Sub, Redisson 분산 락


> 🔗 [Notion 바로가기](https://www.notion.so/lceye/LC-Eye-2a2094d4983480369aa4fe1a6163688f?source=copy_link)

## :baseball: IncheonPhoenix 프로젝트
> **기간:** 2025.09.26 ~ 2025.10.31 <br/>
> **기술스택:** Spring Boot · React · Redis <br/>
> **역할:** 조장 / 좌석교환 / 푸시알림

**IncheonPhoenix**는 일반·시니어 모드와 음성 안내 기능을 통해 고령층의 접근성을 보완하고 <br/>
**자동매칭**과 시니어 전용 좌석 우선 배정을 제공하고
**좌석 교환** 기능으로 재예매의 불편을 줄여 효율적인 예매 경험을 지원하는 예매 플랫폼입니다.

**핵심 구현**
- **좌석 교환** : 같은 구역내 교환신청을 켜놓은 회원의 좌석과 좌석교환 구현
- **Gemini 연동 챗봇** : 가까운 기일내 경기 3개와 좌석에 대한 정보를 알려주는 챗봇 구현 
- **푸시 알림** : 교환신청, 수락, 거절 시 webSocket을 사용하여 푸시알림 전송

> 🔗 [GitHub 바로가기](https://github.com/l-yeong/Phoenix)
> 🔗 [발표자료 보기](https://buly.kr/58THQ1o)

## 🥩 BestMeat 프로젝트
> **기간:** 2025.08.22 ~ 2025.09.12 <br/>
> **기술스택:** Spring Boot · JSP · WebSocket <br/> 
> **역할:** 발표 / 길찾기 QR / 검색 및 정렬
 
**BestMeat**는 사용자가 여러 정육점의 가격과 정보를 <br/>
**실시간 채팅**으로 비교하고 문의할 수 있는 비대면 중개 플랫폼입니다.

**핵심 구현**
- **QR코드 길찾기** : 회원 거주지 기준 정육점까지의 길찾기 url로 이동하는 QR코드 출력
- **검색 및 정렬 기능** : 사용자가 원하는 제품 검색 기능 및 거리, 평점, 조회수별 정렬 구현
- **지도 클러스터링** : 정육점 위치를 찍은 마커들을 클러스터링 하여 UI개선
